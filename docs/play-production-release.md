- **XCover 5 / SM-G525N / Android 14:** 2026-11-02 Play에서 code 9를 실제 다운로드·설치하고 앱 첫 화면 실행을 확인했다. 설치 출처는 `com.android.vending`이었다. 이후 사용자 요청으로 앱 삭제·패키지 및 서비스 부재를 확인했다. 접근성 서비스 활성화·외장 입력 동작은 미검증이다. 상시 켜짐 OFF·화면 꺼짐 30초를 유지했다.
- **Android 16 에뮬레이터의 Play APK 검사:** ADB 설치 성공. 로그인되지 않은 Play 스토어로 라이선스 확인이 이어져 앱 첫 화면 실행과 실제 Play 다운로드는 미검증이다. 별도의 소스 빌드 회귀 검사와 구분한다.
- **Galaxy Tab A9 / Android 16:** 사용자 기기의 Play 다운로드 실패 원인은 미확정이다. 웹에서 원격 설치를 접수하거나 ‘이미 설치됨’으로 표시한 것만으로 기기 내 설치·실행을 확인하지 않았다. 프로덕션 전환으로 해결된다고 보장하지 않는다.
- 실물 태블릿의 접근성·Bluetooth/USB 입력, DeX, 외부 화면 및 장시간 배터리 영향은 추가 검증이 필요하다.

## 실행 방식과 접근성 선언

다른 앱에서 입력을 처리하려면 `AccessibilityService`를 켜 둬야 한다. 설정 화면을 닫아도 작동하며 화면을 항상 켜 둘 필요는 없다. Android가 서비스 시작·재연결을 관리한다. 재부팅이나 시스템 제한 후에는 앱과 Android 접근성 설정에서 상태를 확인한다. 전체 입력 처리는 접근성 서비스를 끄면 중지된다.

RightPress는 일반 마우스·외장 키보드 유틸리티로 `isAccessibilityTool=false`를 유지한다. API는 키 이벤트를 등록 단축키와 비교하고, 화면 요소의 위치·계층·지원 동작을 확인하며, 사용자가 설정한 터치 제스처와 시스템 동작을 수행하는 데 사용한다. 요소 텍스트 읽기, 화면 내용·스크린샷·입력 기록 보관, 개발자에게 데이터 전송은 구현하지 않았다. 설정과 동의 상태는 기기에 저장한다.

앱 내 고지와 명시적 동의 후 서비스를 켜는 흐름을 유지한다. 스토어 설명과 심사 영상도 같은 사용 목적·권한·중지 방법을 보여줘야 한다.

## 1.0.2 (12) 접근성 설정 안내 — 정식 출시

메인 연결 버튼과 도움말 모두에서 Android 접근성 설정을 열기 전에 별도 경로 안내를 보여준다. 기존 접근성 고지·동의와 경로 안내를 분리하고 31개 로캘에 번역 문구를 추가했다.

- 삼성: **설치된 앱 → 현재 언어의 서비스명 → 사용 ON → 허용**.
- 일반: **다운로드한 앱 → 현재 언어의 서비스명 → 사용 ON → 허용**.

안내에는 현재 언어의 `service_name`을 넣는다. 이미 저장된 동의를 다시 요청하지 않으며, 경로 안내 취소는 설정·저장된 동의 상태를 바꾸지 않는다. 목록 스크롤·강조는 지원하는 설정 화면에 전달하는 힌트다. 서비스 상세 스위치 화면을 바로 여는 것은 보장하지 않는다.
